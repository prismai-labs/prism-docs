# Documentation directory

This directory is reserved for cross-project architecture notes, decision records, and shared developer guidance.

## Canonical product references

- Main Windows product: [Prism AI handbook](https://github.com/prismai-labs/Prism-Ai/tree/Main/docs)
- Offline research toolkit: [Prism Zero validation](https://github.com/prismai-labs/prism-zero/blob/main/VALIDATION.md)
- SDK: [Prism SDK README](https://github.com/prismai-labs/prism-sdk#readme)

Product installation, limitations, security, and release-specific instructions remain in their source repositories to avoid stale duplicated instructions.

## Planned documentation structure

Add a page only when it has a clear owner and source of truth:

- `architecture/` — cross-component architecture and reviewed diagrams
- `decisions/` — dated architecture decision records
- `developer/` — setup, testing, and contribution guidance shared across repositories
- `operations/` — verified deployment, recovery, and maintenance runbooks

No production deployment or hosted API is implied by this structure.
