## Project maturity

Prism AI is the main Windows product. Prism Zero is an experimental offline toolkit. The SDK, MCP server, and docs workspace are early-stage supporting components. The private web prototype is separate from the Windows product. Do not treat scaffolds or experimental components as hosted production services.

## Documentation principles

- Keep product-specific instructions next to the code or release they describe.
- Distinguish tested behavior from planned or experimental work.
- State the affected version when instructions are release-specific.
- Preserve historical release notes as historical records.
- Verify third-party claims and citations independently.
